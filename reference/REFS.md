# References consulted (no Nintendo assets copied into this repo)

Numbers, layouts, course/hazard lists and rules in [SPEC.md](SPEC.md) were derived from
public documentation of the original game — listings and descriptions, not ripped media:

- Super Mario Wiki — "Mario Kart 64" (modes, cups, courses, items): https://www.mariowiki.com/Mario_Kart_64
- Super Mario Wiki — "Drift" and Mario Kart Wiki — "Mini-Turbo" (counter-steer wiggle, yellow→red smoke): https://www.mariowiki.com/Drift
- StrategyWiki — "Mario Kart 64/Extra Mode" (mirrored courses, unlock): https://strategywiki.org/wiki/Mario_Kart_64/Extra_Mode
- GameFAQs MK64 guide by Crazyreyn (staff-ghost unlock times used for lap-pace targets:
  Luigi 1'52"00, Mario 1'30"00, Royal 2'40"00 over 3 laps): https://gamefaqs.gamespot.com/n64/197860-mario-kart-64/faqs/42451
- Community longplay track/chapter listings for cup/track order and engine classes (YouTube).
- Sibling project ~/projects/smash64: `src/net/room.js` (PeerJS room pattern, ICE servers) and
  `src/core/touch.js` (nipplejs + thumb-button pattern) — approach reused, code adapted.

Reference frames pulled from the wiki galleries above live in `reference/frames/` (course
vistas + title screen) and `reference/gameplay/` (per-course MK64 screenshots/gallery images),
used only for side-by-side comparison in `comparisons/` — they are research material credited
to Super Mario Wiki contributors, never used as in-game assets (the game ships only original
procedural textures and models).
